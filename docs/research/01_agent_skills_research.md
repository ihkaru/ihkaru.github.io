## 1. Analisis Perintah `npx skills add faidzagustiawan/portofolio --all -g -y`

### 1.1 Komponen Perintah
Perintah ini merupakan pemanggilan CLI resmi dari standar **Open Agent Skills** (dikenal melalui platform [skills.sh](https://skills.sh) / Vercel Labs):

| Bagian | Fungsi & Mekanisme |
| :--- | :--- |
| `npx skills` | Menjalankan CLI `skills` tanpa instalasi global awal via Node.js/Bun. |
| `add` | Subcommand untuk mengunduh dan mendaftarkan skill dari remote repository. |
| `faidzagustiawan/portofolio` | Shorthand GitHub target repository (`owner/repo`). CLI mencari direktori `.agents/skills/` atau `skills/` pada repo ini. |
| `--all` | Mengunduh **semua** skill yang terdaftar di dalam repository tersebut (tidak hanya satu skill tertentu). |
| `-g` (*global*) | Menginstal skill secara global ke direktori agent user (`~/.agents/skills/`), sehingga skill dapat diakses oleh AI agent di seluruh project pada sistem operasi tersebut. |
| `-y` (*non-interactive / yes*) | Melewati konfirmasi interaktif (auto-accept semua prompt perizinan dan pemilihan). |

## 3. Rincian 6 Modul Skill Antislop & Relevansinya untuk Portofolio

Sistem **Anti-Slop** dirancang dengan premis:
> *"The design should feel crafted by a human designer, not generated by AI."*

AI sering kali memproduksi UI web yang seragam, klise, dan murahan (*AI slop*): gradien ungu-biru neon, kartu mengambang dengan glassmorphism berlebihan, bento grid template, ikon hiasan tanpa fungsi, copy marketing klise ("revolutionary", "cutting-edge", "seamless"), dan testimoni/metrik palsu.

Berikut adalah 6 skill yang diekstrak dan siap digunakan:

### 3.1 `antislop` (Core Filter & Gatekeeper)
- **Fungsi**: Filter utama yang wajib diaktifkan sebelum dan sesudah pekerjaan UI.
- **Mekanisme**:
  - **Liveliness Dials**: Mendefinisikan status energi, ritme, dan gerak:
    - `ENERGY` (1: Tenang & fokus, 2: Terstruktur & kontras kuat, 3: Dinamis & ekspresif).
    - `RHYTHM` (1: Grid seragam, 2: Variasi teratur, 3: Asimetris deliberate).
    - `MOTION` (1: Static/hover only, 2: Transisi halus kontekstual, 3: Cinematic choreo).
  - **Purpose-Gate**: Teknik visual (gradien, shadow, border radius, ikon) dilarang menjadi *default* tanpa tujuan hierarki yang jelas.
  - **Zero Fabrication**: Melarang keras mencantumkan klaim performa, klien, atau testimoni buatan (harus berbasis fakta riil dari kode/repositori).

### 3.2 `antislop-ui` (Visual & Layout Craft)
- **Fungsi**: Memandu keputusan styling, warna, tipografi, dan komponen.
- **Aturan Krusial**:
  - **Palet Warna**: Batasi 2–3 warna inti + 1 warna aksen terarah (hindari gradien pelangi atau tema ungu-cyan generic).
  - **Dose Cap**: Glassmorphism dan efek glow dibatasi maksimal pada 1–2 elemen fokus utama (bukan di semua navbar, card, dan modal).
  - **Border Radius**: Gunakan `rounded-xl` terukur untuk hierarki struktural, bukan pill-shape (`rounded-full`) seragam di semua tombol dan kartu.
  - **Tata Letak**: Hindari bento-grid mosaic template yang dipaksakan. Susun layout berdasarkan keputusan navigasi pengunjung.

### 3.3 `antislop-copywriting` (Authentic Voice & Tone)
- **Fungsi**: Membasmi bahasa teks AI yang kaku dan penuh jargon klise.
- **Larangan Khusus**:
  - Dilarang menggunakan kata klise AI: *"delve"*, *"tapestry"*, *"testament"*, *"unleash"*, *"cutting-edge"*, *"seamless"*, *"game-changer"*, *"groundbreaking"*.
  - Dilarang menggunakan antusiasme palsu (terlalu banyak tanda seru atau kalimat puitis tanpa data).
  - Deskripsi project harus langsung menjelaskan: **Masalah apa yang diselesaikan**, **arsitektur apa yang dipakai**, dan **hasil/bukti riil dari repo**.

### 3.4 `antislop-human` (Aksesibilitas & Ergonomi)
- **Fungsi**: Memastikan portofolio ramah pengguna manusia nyata.
- **Kriteria**:
  - **Rasio Kontras**: Minimal 4.5:1 untuk teks biasa dan 3:1 untuk elemen interaktif/grafik (disertai script audit `contrast-check.py`).
  - **Aksesibilitas Keyboard**: Focus state jelas (`focus-visible:ring-2`), navigasi tab teratur, dan tidak ada trap interaktif.
  - **Motion Sensitivity**: Kepatuhan terhadap `prefers-reduced-motion` untuk pengunjung dengan sensitivitas vestibular.

### 3.5 `antislop-layoutmobile` (Mobile-First & Touch Targets)
- **Fungsi**: Menjamin integritas layout pada layar smartphone dan tablet.
- **Kriteria**:
  - **Touch Target**: Semua tombol dan link interaktif memiliki ukuran target sentuh minimal $\ge 44 \times 44\text{ px}$.
  - **Zero Overflow**: Tidak ada elemen yang bocor ke sumbu horizontal (`overflow-x: hidden` bukan solusi tambal sulam; struktur grid harus elastis).
  - **Fluid Typography & Spacing**: Skala tipografi responsif yang mudah dibaca tanpa harus zoom manual.

### 3.6 `antislop-code` (Code Hygiene & Non-Slop Comments)
- **Fungsi**: Disiplin penulisan komentar dan struktur kode.
- **Kriteria**:
  - Melarang komentar AI yang hanya menyatakan apa yang dilakukan kode (`// increment i by 1`).
  - Komentar hanya diperbolehkan untuk menjelaskan **alasan (WHY)** keputusan arsitektural atau penanganan edge-case rumit.

## 4. Cara Menggunakan Skill Ini pada Project Portofolio `ihkaru.github.io`

1. **Lokasi File Skill**:
   - Seluruh skill telah disalin ke: [docs/research/skills/](file:///root/projects/ihkaru.github.io/docs/research/skills/)
   - Didaftarkan ke workspace project: [.agents/skills/](file:///root/projects/ihkaru.github.io/.agents/skills/)
   - Tersambung secara global ke: `~/.agents/skills/`
2. **Design Direction Contract (`DESIGN.md`)**:
   - Sebelum mengkoding tampilan portofolio, buat file `DESIGN.md` yang menetapkan identitas, palet warna, tipografi, dan dial liveliness (`ENERGY 2 / RHYTHM 2 / MOTION 2`).
3. **Audit Gate Otomatis**:
   - Setiap iterasi UI dapat diverifikasi menggunakan checklist antislop dan script verifikasi kontras warna `python3 docs/research/skills/antislop-human/contrast-check.py`.
